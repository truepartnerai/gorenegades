# Project Thread Guide

Use one ChatGPT Project: **Go Renegades Website + Content**

## Thread 1 — Content Engine
Purpose: manage the machine.

Use for:
- blog/podcast architecture
- RSS
- publishing SOP
- categories/tags
- editorial calendar
- repurposing system
- content migrations
- SEO/content structure
- ongoing content strategy
- analytics and content performance
- improving the workflow

This is the best thread for questions like:
- "How should we organize the blog?"
- "Should this be an article or podcast?"
- "What's our publishing cadence?"
- "How do we migrate the old episodes?"
- "How should the RSS feed work?"

## Thread 2 — Website Build
Purpose: build and maintain the actual site.

Use for:
- homepage
- CRM page
- Academy page
- Community page
- About page
- navigation/footer
- blog/podcast templates
- design
- mobile
- Astro
- GitHub
- Vercel
- domains/redirects
- technical SEO
- landing pages

This is the best thread for:
- "Change the homepage hero."
- "Publish this landing page."
- "Fix the mobile nav."
- "Point this domain to the podcast page."

## Thread 3 — Content Production
Purpose: the raw-content factory.

Drop in:
- transcripts
- videos
- voice notes
- old emails
- Facebook/LinkedIn posts
- Power Hours
- podcast recordings
- screenshots
- notes
- rough ideas

Example instructions:
- "Turn this into an article."
- "Make this a podcast episode."
- "Pull five shorts from this."
- "Turn this into everything useful."
- "Publish this."

## Rule of Thumb
If the question is about **the system**, use Content Engine.

If it is about **the website itself**, use Website Build.

If you are handing over **raw material**, use Content Production.

Do not create separate projects for the blog and podcast. They are two outputs of the same Marketing Renegades content engine.
